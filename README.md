# ไปเรื่อย (Travel Planner)

เว็บแอปช่วยวางแผนเที่ยวในประเทศไทย จัดสถานที่และเวลาแยกเป็นรายวัน ดูเส้นทางของแต่ละวันบนแผนที่ แล้วชวนเพื่อนมาช่วยกันแก้แผนเดียวกันได้ ถ้าไม่อยากวางแผนเอง ก็เลือกแผนที่คนอื่นแชร์ไว้บนหน้าสำรวจทริปแล้วคัดลอกไปปรับใช้ได้ทันที

- **วางแผนทีละวัน** เพิ่มสถานที่ ใส่เวลา ลากเปลี่ยนลำดับ และปักหมุดจากลิงก์ Google Maps
- **แชร์และแก้ด้วยกัน** กำหนดสิทธิ์ดูหรือแก้ไขให้เพื่อน ทุกคนเห็นการเปลี่ยนแปลงโดยไม่ต้องรีโหลด
- **สำรวจทริป** ค้นหาและกรองแผนจากทั่วไทยทั้ง 77 จังหวัด แล้วคัดลอกมาเป็นแผนของตัวเอง

**สร้างด้วย** Next.js · React · TypeScript · Prisma · PostgreSQL · Docker

วิธีติดตั้งและพัฒนาต่อ ดูได้ที่ [คู่มือติดตั้ง](docs/SETUP.md)
